# WSID_FE
## 로컬 실행 방법

**1. 프로젝트 클론**
```bash
git clone https://github.com/geumsappa/WSID_FE.git
cd WSID_FE-main
```

**2. 패키지 설치**
```bash
npm install
```

**3. 개발 서버 실행**
```bash
npm run dev
```

**4. 브라우저 접속**

http://localhost:8443/

> Node.js 20.19+ 또는 22.12+ 필요  
> 모든 명령어는 `package.json`이 있는 폴더에서 실행하세요.
